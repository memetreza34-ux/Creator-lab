# Phase 06 — Analytics & Learning Loop

## Goal

Turn real performance data into evidence-based decisions.

## Work

- provider metric sync
- metric snapshots and freshness
- normalized cross-platform metrics without hiding platform differences
- post/account/time filters
- top/worst content
- evidence-linked insight generation
- sufficient/insufficient sample thresholds
- actions: create similar content / create experiment

## Acceptance

Every generated insight can show the data behind it, its sample size, and freshness. AI interpretation is separated from measured metrics.
