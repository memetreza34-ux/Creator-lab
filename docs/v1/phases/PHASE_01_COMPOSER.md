# Phase 01 — Composer Excellence

## Goal

Turn the existing Composer into a reliable destination-aware creation workflow.

## Work

- capability-aware destination selection
- deterministic platform validation
- platform-specific override lifecycle
- media validation and workspace ownership
- preview accuracy
- save/edit draft behavior
- clear publish/schedule availability based on real capabilities
- AI apply/reject/history UX hardening
- accessibility and error states

## Acceptance

A creator can create, edit, save, and validate a multi-destination draft without losing content or being misled by unsupported actions.
