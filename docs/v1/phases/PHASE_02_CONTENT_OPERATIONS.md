# Phase 02 — Content Operations

## Goal

Make Pipeline, Media, Posts, and Composer one coherent content lifecycle.

## Work

- pipeline ordering/stage invariants
- sourceContentItemId traceability
- pipeline -> composer -> post round trip
- media folders/assets ownership and lifecycle
- posts filtering/status behavior
- deletion/orphan rules
- consistent search/filter semantics

## Acceptance

An idea can become a draft while preserving source traceability, and content/media lifecycle operations do not create broken references.
