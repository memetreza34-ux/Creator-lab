# Phase 07 — Experiments

## Goal

Make experimentation a disciplined learning tool rather than decorative A/B cards.

## Work

- hypothesis
- experiment type
- source content/post links
- variants
- primary metric
- observation window
- outcome
- sample/evidence display
- insufficient-data state
- AI explanation with limitations
- reuse learning in Composer

## Acceptance

The system can record and explain an experiment without declaring a winner when evidence is inadequate.
